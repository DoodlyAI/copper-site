Privacy policy

COPPER is a personal app used only by its owner. This page explains what it does with Google Calendar data.

What COPPER reads

  • The list of calendars on the connected Google account.
  • Events for the next 14 days on the calendars chosen in COPPER: title, start and end time, whether it's all-day, location, and attendees' names.

COPPER doesn't read event descriptions or attachments.

What COPPER writes

COPPER creates one calendar of its own, named "COPPER", and adds, moves and removes planning blocks on it. It never changes or deletes any other calendar or event.

Where the data is kept

Calendar data is stored only on the owner's own computer, in COPPER's local database. The sign-in token Google issues is kept there too, and is never published or shared.

Sharing

Calendar data is never sold, never used for advertising, and never shared with anyone else, with one exception: to suggest which meetings relate to which goals, an event's title, time and attendees' names may be sent to Anthropic's Claude API, which processes the request and returns a suggestion. Event descriptions are never sent.

COPPER's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions: choose COPPER, then remove its access. COPPER then stops reading and writing calendar data, and the locally stored calendar data can be deleted from the owner's computer.

Changes

If this policy changes, this page is updated. Last updated: October 22, 2026.
